# ナーフ射的ゲーム (Nerf Target Projection Mapping Game)

プロジェクターとPCカメラを組み合わせた、**プロジェクションマッピング型インタラクティブ的当てゲーム**です。  
壁やスクリーンに投影した「的」にナーフ弾が命中すると、カメラが弾を瞬時に認識してリアルタイムに着弾エフェクト・弾痕・スコアが加算されます。

---

## 🎯 主な特徴

1. **2画面リンク構成**
   - **プロジェクター画面 (`Projector View`)**: 的、スコアボード、命中アニメーション、弾痕を投影。`F` キーでフルスクリーン化。
   - **カメラ監視画面 (`Camera Monitor`)**: PC側でカメラ映像、アライメント枠、弾センサーマスクを確認。
2. **全自動 四隅キャリブレーション（フラッシュ式）**
   - ボタン一つでプロジェクターが一瞬光り、カメラが壁に映った的の四隅を100%自動認識。斜めからの投影でも透視変換（ホモグラフィ）で完全補正されます。
   - 手動での4点クリック設定や、矢印キーによる1px単位の精密微調整にも対応。
3. **ナーフ弾（青＋オレンジ）高精度カラー検知**
   - ナーフのエリートダーツ（青いボディ ＋ オレンジ色の先端）の色相（HSV）と動体差分を掛け合わせることで、人の影やプロジェクターの光による誤反応を徹底排除。
4. **効果音＆演出**
   - 着弾した位置に広がる波紋アニメーションと「100 PTS! (BULLSEYE!)」ポップアップ。
   - 得点に応じた周波数の命中音（ビープ音）。

## 🚀 起動方法

### Windowsの場合（推奨）
**`run_game.bat`** をダブルクリックするだけ！  
（Pythonの確認、必要ライブラリ `opencv-python`, `numpy` の自動インストールからゲーム起動まで全自動で行われます）

### コマンドラインから起動する場合
```bash
pip install opencv-python numpy
python nerf_target.py
```

## 🎮 操作方法

| 操作 | 機能 |
| :--- | :--- |
| **`C` キー** / **`[AUTO ALIGN]`** | **四隅自動認識**: プロジェクターが一瞬光り、四つ角を全自動でピッタリ合わせます |
| **`M` キー** / **`[CLICK 4-PT]`** | **4点手動設定**: カメラ画面上で「左上➜右上➜右下➜左下」を4回クリックして角を設定 |
| **マウスクリック** | カメラ画面上でクリックした場所に最も近い角を移動 |
| **`TAB` キー** | 調整する角を順繰りに選択 |
| **矢印キー (↑ ↓ ← →)** / **WASD** | 選択中の角を1ピクセル単位で微調整 |
| **`R` キー** / **マウス右クリック** | スコア＆背景のリセット |
| **`F` キー** | プロジェクター画面の **フルスクリーン（全画面）切り替え** |
| **`ESC` / `Q`** | ゲーム終了 |

## 🛠️ 必要要件
- OS: Windows 10 / 11 (または Linux)
- Python 3.8 以上
- ライブラリ: `opencv-python`, `numpy`
- 機材: PC、Webカメラ（内蔵またはUSB）、プロジェクター、ナーフ銃＆弾
